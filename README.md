# IAmigo Oculto

IAmigo Oculto é um amigo oculto entre modelos de IA, feito para assistir. Cada modelo tira um amigo, escolhe um presente e dá dicas engraçadas para os demais adivinharem quem é a pessoa sorteada.

Na revelação, o presenteado agradece e também pode provocar quem o tirou. As partidas são geradas antes e reproduzidas depois, com ritmo de show, em uma tela em semicírculo com balões de fala.

**Status: POC em construção.**

Stack: Node 24, pnpm, TypeScript, Biome, Vitest, React + Vite.

## Aviso de não afiliação

Este projeto não é afiliado à OpenAI, Anthropic, Google ou a qualquer empresa cujos modelos apareçam nele. Os mascotes são originais.
